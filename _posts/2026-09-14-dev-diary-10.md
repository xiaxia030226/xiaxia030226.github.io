本篇记录武器系统的重做：删除铁剑，新增普通手枪（点击单发）和普通机枪（长按连发），两把枪共用一个 GunWeapon 类，差异全部由 ScriptableObject 配置驱动；子弹是对象池管理的实体。

## 我做了什么

1. 删除 SwordWeapon，新建 GunWeapon（手枪机枪共用）和 Bullet（子弹实体）
2. 新建 WeaponConfig、BulletConfig 两个 ScriptableObject 配置类和对应的查询表
3. 在 Resources/Configs/Weapons/ 下创建三个配置资产：Pistol、MachineGun、NormalBullet（我创建资产，AI 填数值）
4. WeaponBase 加 IsAutomatic 属性，Player 按它选择输入检测方式
5. WeaponSystem.Setup 按配置装配两把枪，并注册子弹对象池

## 配置设计

武器和子弹配置资产放同一个文件夹 Configs/Weapons/，LoadAll 按类型过滤互不干扰。

武器配置字段：弹夹、伤害、换弹时间、射速 RPM（0 表示非自动）、是否连发、子弹 id。子弹配置字段：子弹伤害、飞行速度、预制体路径。

两个设计决策：

- 命中伤害 = 武器伤害 + 子弹伤害，两个字段都有意义，升级面板的伤害强化也直接生效
- 手枪没有射速配置项，代码里写死固定攻击间隔 0.15 秒防止极端连点；机枪攻击间隔 = 60 / RPM

三个资产的数值：

| 资产 | 关键值 |
|------|--------|
| Pistol | 弹夹 12，伤害 10，换弹 1.5 秒，非自动 |
| MachineGun | 弹夹 50，伤害 6，换弹 2.5 秒，RPM 600（每秒 10 发），连发 |
| NormalBullet | 伤害 5，速度 30 米/秒，预制体 Prefabs/Bullet |

## 配置表的加载

沿用敌人配置的模式：静态查询表 + 懒加载，首次访问时 LoadAll 整个文件夹：

```csharp
private static Dictionary<string, WeaponConfig> Configs => sConfigs ??= LoadAll();

private static Dictionary<string, WeaponConfig> LoadAll()
{
    var configs = new Dictionary<string, WeaponConfig>();
    foreach (var config in Resources.LoadAll<WeaponConfig>("Configs/Weapons"))
    {
        if (configs.ContainsKey(config.Id)) { Debug.LogError(...); continue; }
        configs[config.Id] = config;
    }
    return configs;
}
```

## GunWeapon：一个类装所有枪

手枪和机枪行为完全一致（发射子弹），差异只在数据，所以共用一个类，构造时把配置映射成基类参数：

```csharp
public GunWeapon(WeaponConfig config, BulletConfig bulletConfig,
    IGameObjectPoolSystem pool, Transform bulletParent)
    : base(config.Id, config.Name, WeaponResourceType.Ammo,
          config.Magazine,          // 弹夹 = 弹药型资源上限
          1f,                       // 每发耗 1 发子弹
          0f, config.ReloadTime,    // 耗尽后按换弹时间补满
          config.RoundsPerMinute > 0f ? 60f / config.RoundsPerMinute : 0.15f,
          config.Damage, config.IsAutomatic) { ... }
```

基类 WeaponBase 的弹药机制正好就是弹夹：资源耗尽自动进入 Refilling 状态，换弹时间到补满——这套现成的状态机不用改一行。

发射就是取子弹、摆到枪口、初始化飞行参数：

```csharp
protected override void DoAttack(Transform owner)
{
    var muzzle = owner.position + owner.rotation * MuzzleOffset;
    var bulletObject = mPool.Spawn(mBulletConfig.Id, muzzle, owner.rotation, mBulletParent);
    bulletObject.GetComponent<Bullet>().Setup(mBulletConfig.Id,
        Mathf.RoundToInt(Damage) + mBulletConfig.Damage,   // 武器伤害 + 子弹伤害
        mBulletConfig.Speed, owner.forward);
}
```

## Bullet：对象池实体

子弹三个职责：直线飞、命中结算、到距回收。每次从池中取出时由武器 Setup 重置状态：

```csharp
public void Setup(string poolKey, int damage, float speed, Vector3 direction)
{
    mPoolKey = poolKey;
    mDamage = damage;
    mSpeed = speed;
    mDirection = direction.normalized;
    mTraveledDistance = 0f;
}

private void OnTriggerEnter(Collider other)
{
    var enemy = other.GetComponentInParent<Enemy>();
    if (enemy == null || !enemy.IsAlive) return;
    enemy.TakeHit(mDamage);
    RecycleSelf();
}
```

飞满 60 米自动回池。预制体侧：Collider 勾 Is Trigger，加 kinematic Rigidbody（触发器事件需要至少一方有 Rigidbody）。

## 输入分支：单发与连发

Player 不再统一用 IsPressed，改为读当前武器的 IsAutomatic 选检测方式：

```csharp
var weapon = GetWeaponSystem().CurrentWeapon;
var triggered = weapon.IsAutomatic
    ? GameInput.Attack.IsPressed()              // 机枪：长按每帧尝试，射速由攻击间隔限制
    : GameInput.Attack.WasPressedThisFrame();   // 手枪：按下瞬间只发一次
if (triggered) GetWeaponSystem().TryAttackCurrent();
```

为此 WeaponSystem 暴露了 CurrentWeapon 属性，升级面板顺手也从 Weapons[0] 改成作用在当前手持武器上。

## 装配入口

WeaponSystem.Setup 负责把配置变成运行时的枪和子弹池：

```csharp
public void Setup(Transform owner, Transform bulletParent)
{
    mOwner = owner;
    // 注册子弹对象池（多把枪共用同种子弹时用集合去重，预热 32 颗）
    // 装配：手枪入槽 1，机枪入槽 2
    mWeapons.Add(CreateGun(WeaponConfigTable.PistolId, pool, bulletParent));
    mWeapons.Add(CreateGun(WeaponConfigTable.MachineGunId, pool, bulletParent));
}
```

GameRoot 把环境里建好的 BulletRoot 挂点传进来，子弹实例统一挂在它下面。
