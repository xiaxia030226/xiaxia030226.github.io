目前还没想好具体做什么类型的游戏，所以先从搭建基础框架开始。第一步是实现项目中最常用的设计模式——**单例模式**。

## 基础框架结构

基础框架统一放在 `Assets/Scripts/GameFrameWork/` 目录下，按功能模块划分子文件夹。本篇先搭建 `Singleton` 模块，包含两个泛型单例基类。

```
Assets/Scripts/GameFrameWork/
└── Singleton/
    ├── Singleton.cs                 # 普通 C# 泛型单例
    └── MonoBehaviourSingleton.cs    # MonoBehaviour 泛型单例
```

## 1. 普通 C# 单例 —— `Singleton<T>`

适用于不需要挂载到场景中的纯逻辑管理类，如数据管理器、配置管理器等。

```csharp
public class Singleton<T> where T : new()
{

    private static T _instance;

    public static T Instance
    {
        get
        {
            if (_instance == null)
            {
                _instance = new T();
            }
            return _instance;
        }
    }

}
```

### 核心要点

- **泛型约束 `where T : new()`**：要求类型 `T` 必须有一个无参构造函数，这样才能在 Instance 内部通过 `new T()` 创建实例。
- **懒加载（Lazy Initialization）**：实例在第一次访问 `Instance` 时才被创建，而不是在程序启动时。
- **非线程安全**：当前实现没有加锁，在多线程环境下可能创建多个实例。后续如果需要，可以加上 `lock` 机制。
- **适用场景**：纯数据管理类、工具类等不需要依赖 Unity 生命周期的模块。

### 使用示例

```csharp
public class DataManager : Singleton<DataManager>
{
    public string gameName = "MyGame";
    
    public void LoadData()
    {
        // 加载游戏数据
    }
}

// 在任何地方调用
DataManager.Instance.LoadData();
```

## 2. MonoBehaviour 单例 —— `MonoBehaviourSingleton<T>`

适用于需要用到 Unity 生命周期（`Awake`、`Start`、`Update` 等）的管理类，如音频管理器、协程管理器等。

```csharp
using System.Collections;
using System.Collections.Generic;
using UnityEngine;

public class MonoBehaviourSingleton<T> : MonoBehaviour where T : MonoBehaviour
{

    public static T _instance;

    public static T Instance
    {
        get
        {
            if (_instance == null)
            {
                GameObject obj = new GameObject(typeof(T).Name);
                _instance = obj.AddComponent<T>();
                DontDestroyOnLoad(obj);
            }
            return _instance;
        }
    }

}
```

### 核心要点

- **泛型约束 `where T : MonoBehaviour`**：要求类型 `T` 必须继承自 `MonoBehaviour`，这样才能被挂载到 `GameObject` 上。
- **自动创建 GameObject**：首次访问时自动创建一个以类名命名的 `GameObject`，并将 `T` 组件附加到上面。
- **`DontDestroyOnLoad`**：确保切换场景时单例对象不会被销毁，保持全局唯一。
- **适用场景**：音频管理器（AudioManager）、场景管理器（SceneManager）、协程管理器（CoroutineManager）等需要 Unity 生命周期的全局模块。

### 使用示例

```csharp
public class AudioManager : MonoBehaviourSingleton<AudioManager>
{
    private AudioSource audioSource;

    private void Awake()
    {
        audioSource = gameObject.AddComponent<AudioSource>();
    }

    public void PlaySound(AudioClip clip)
    {
        audioSource.PlayOneShot(clip);
    }
}

// 在任何地方调用
AudioManager.Instance.PlaySound(someClip);
```
