本篇记录阶段二战斗闭环的两个核心部分：对象池驱动的波次刷怪，以及玩家的移动、朝向、攻击与切枪逻辑。涉及四个文件：GameObjectPoolSystem、EnemySpawnSystem、Enemy、Player。

## GameObjectPoolSystem：按 key 管理多个对象池

刷怪时如果每次 Instantiate、每次 Destroy，敌人一多就会卡顿。对象池的思路是：注册时预热一批敌人存起来，刷怪时取出来用，打死时放回去，整个游戏过程不产生新的创建和销毁。

我用字典按字符串 key 管理多个池，这样史莱姆、水晶、将来的子弹各有各的池，互不干扰。底层直接复用 QFramework 自带的 SimpleObjectPool，对外只暴露注册、取用、回收三个动作：

```csharp
public interface IGameObjectPoolSystem : ISystem
{
    void Register(string key, Func<GameObject> factory, int initialCount = 0);
    GameObject Spawn(string key, Vector3 position, Quaternion rotation, Transform parent = null);
    void Recycle(string key, GameObject instance);
}
```

实现里最核心的是 Register，SimpleObjectPool 接收两个委托，一个负责创建，一个负责回池重置：

```csharp
public void Register(string key, Func<GameObject> factory, int initialCount = 0)
{
    // SimpleObjectPool 的第一个委托负责创建对象，第二个委托负责对象回池时的重置。
    mPools.Add(key, new SimpleObjectPool<GameObject>(() =>
    {
        var instance = factory();
        instance.SetActive(false);
        return instance;
    }, instance => instance?.SetActive(false), initialCount));
}
```

几个值得说的点：

- 回池重置只做 SetActive(false)。敌人的血量、目标等运行状态不在池层重置，而是由 Enemy.OnSpawn 完成，池层只负责显示开关。
- Spawn 里池空了不会报错，Allocate 会自动调用工厂现造一个，池容量是弹性的。
- 真正 Destroy 只发生在 OnDeinit（架构销毁时），游戏运行期间没有销毁开销。

## EnemySpawnSystem：波次调度与生成

刷怪系统负责三件事：按波次表定时生成敌人、判断本波是否清场、清场后推进下一波。它是 AbstractSystem，不是 MonoBehaviour，所以 GameRoot 每帧手动调 Tick。Tick 里的状态推进是核心：

```csharp
public void Tick(float deltaTime)
{
    // 两波之间的等待间隔：倒计时结束就开下一波。
    if (mWaitingNextWave)
    {
        mNextWaveTimer -= deltaTime;
        if (mNextWaveTimer <= 0f) StartWave(mCurrentWave + 1);
        return;
    }

    if (!mWaveRunning) return;

    SpawnBySchedule(deltaTime);

    // 必须同时满足"配置中的敌人已生成完"和"场上存活数为 0"，才算真正清场。
    if (AllGroupsSpawned() && this.GetModel<IEnemyModel>().AliveCount.Value == 0)
    {
        CompleteCurrentWave();
    }
}
```

单只敌人的生成用极坐标，并配合对象池完成取用：

```csharp
private void SpawnEnemy(string enemyId)
{
    // 随机角度加随机半径，生成位置落在玩家周围 15~20 米的圆环上。
    var angle = Random.Range(0f, Mathf.PI * 2f);
    var radius = Random.Range(SpawnRadiusMin, SpawnRadiusMax);
    var position = mPlayer.position + new Vector3(Mathf.Cos(angle), 0f, Mathf.Sin(angle)) * radius;

    // 池子负责取物体，取出来后立刻调 OnSpawn 重置运行状态，两个职责分开。
    var enemyObject = this.GetSystem<IGameObjectPoolSystem>()
        .Spawn(enemyId, position, Quaternion.identity, mParent);
    enemyObject.GetComponent<Enemy>().OnSpawn(EnemyConfigTable.Get(enemyId), mPlayer);
    this.GetModel<IEnemyModel>().AliveCount.Value++;
}
```

几个值得说的点：

- 生成环是 15 到 20 米，敌人不会刷在玩家脸上，也不会刷得太远。
- 清场判定是双条件的：配置里的组全部生成完，且 AliveCount 为 0。如果只看击杀数，生成到一半时可能误判。
- 波次之间不是无缝衔接，清场后等 WaveInterval 秒才开下一波，给玩家喘息时间。
- 敌人预制体通过 Resources.Load 加载一次后缓存在字段里，工厂后续克隆都复用缓存，避免重复 IO。

## Enemy：与对象池配合的敌人实体

对象池复用的物体不会重新走 Awake，所以敌人每次出场都要手动重置状态。我把它做成 OnSpawn 方法，由刷怪系统在取出物体后调用：

```csharp
public void OnSpawn(EnemyConfig config, Transform target)
{
    mConfig = config;
    mTarget = target;
    mCurrentHP = config.MaxHP;
    mNextAttackTime = 0f;
    mIsAlive = true;
}
```

接触伤害的限频也值得记一笔。OnTriggerStay 每个物理帧都会触发，如果直接扣血，一接触就是秒杀，所以用绝对时间做间隔控制：

```csharp
private void OnTriggerStay(Collider other)
{
    if (!mIsAlive || Time.time < mNextAttackTime) return;
    if (other.GetComponent<Player>() == null) return;

    // 用绝对时间限制为配置中的攻击间隔。
    mNextAttackTime = Time.time + mConfig.AttackInterval;
    this.SendCommand(new PlayerTakeDamageCommand(mConfig.ContactDamage));
}
```

死亡时先发事件再回池，顺序不能反：

```csharp
private void Die()
{
    mIsAlive = false;
    // 更新击杀数与存活数……
    this.SendEvent(new EnemyDiedEvent { EnemyId = mConfig.Id, Position = transform.position, ExpValue = mConfig.ExpValue });
    // 最后才将实体回收到对象池。
    this.GetSystem<IGameObjectPoolSystem>().Recycle(mConfig.Id, gameObject);
}
```

经验水晶系统监听 EnemyDiedEvent 时需要死亡位置，位置数据在回池前取好才正确，所以事件必须发在 Recycle 之前。

另外两处小细节：距离判断统一用平方距离（sqrMagnitude）和平方半径比较，省掉开平方；追击时进入攻击范围就停止移动，接触伤害交给触发器处理。

## Player：移动、朝向、攻击与切枪

玩家逻辑集中在四个方法里，Update 按固定顺序调用：移动、朝向、攻击、切枪。移动速度和生命都从 Model 读，表现层不直接改数据。

移动的关键在斜向归一化。同时按 W 和 D 时合成向量的长度是根号 2，不归一化的话斜着走比直走快：

```csharp
private void HandleMove()
{
    var moveInput = GameInput.Move.ReadValue<Vector2>();

    // 斜向同时按两个键时向量长度会大于 1，归一化可避免斜向移动更快。
    if (moveInput.sqrMagnitude > 1f)
    {
        moveInput.Normalize();
    }

    var speed = this.GetModel<IPlayerModel>().MoveSpeed.Value;
    var position = transform.position;
    position += new Vector3(moveInput.x, 0f, moveInput.y) * (speed * Time.deltaTime);
    position.x = Mathf.Clamp(position.x, -MapLimit, MapLimit);
    position.z = Mathf.Clamp(position.z, -MapLimit, MapLimit);
    transform.position = position;
}
```

鼠标朝向没有用 Physics.Raycast，而是把相机射线和 y=0 的数学平面求交。地面没有 Collider，数学平面求交更直接，也少一次物理查询：

```csharp
private void FaceMouse()
{
    // 从相机经过鼠标屏幕位置发一条射线。
    var ray = mMainCamera.ScreenPointToRay(GameInput.MousePosition.ReadValue<Vector2>());
    var plane = new Plane(Vector3.up, Vector3.zero);  // y=0 的水平面

    if (plane.Raycast(ray, out float enter))
    {
        var hit = ray.GetPoint(enter);      // 鼠标指向的地面世界坐标
        var dir = hit - transform.position;
        dir.y = 0f;                          // 只取水平方向
        if (dir.sqrMagnitude > 0.001f)       // 鼠标正悬停在玩家头顶时跳过
        {
            transform.rotation = Quaternion.LookRotation(dir);
        }
    }
}
```

攻击的点击和长按是同一个判断，攻击节奏交给武器自己的 AttackInterval 控制，输入层不做节流：

```csharp
private void HandleAttack()
{
    // IsPressed 按住期间每帧触发；"点击"打一下，"长按"按攻速连续攻击。
    if (GameInput.Attack.IsPressed())
    {
        GetWeaponSystem().TryAttackCurrent();
    }
}
```

切枪有两种方式。数字键用 WasPressedThisFrame 判断按下瞬间，避免按住时每帧重复切换；滚轮是连续值，加阈值过滤滚动结束前的抖动：

```csharp
private void HandleWeaponSwitch()
{
    // 1-9 数字键切到对应槽位（下标 = 数字 - 1）。
    for (var i = 0; i < GameInput.SwitchSlots.Length; i++)
    {
        if (GameInput.SwitchSlots[i].WasPressedThisFrame())
        {
            GetWeaponSystem().SwitchTo(i);
        }
    }

    // 滚轮 y 值越过阈值才切换，过滤滚动结束前的微小抖动。
    var scroll = GameInput.ScrollWeapon.ReadValue<Vector2>().y;
    if (scroll > ScrollThreshold) GetWeaponSystem().SwitchBy(1);
    else if (scroll < -ScrollThreshold) GetWeaponSystem().SwitchBy(-1);
}
```

## 小结

这一轮把战斗闭环的骨架搭起来了：刷怪系统按波次表定时从对象池取敌人，敌人追击玩家并在死亡后回池，玩家用 WASD 移动、鼠标转向、左键攻击、数字键切枪。对象池让敌人反复出场不产生创建销毁开销，System 手动 Tick 让波次调度保持可预测。下一阶段在这个骨架上接入经验水晶和升级三选一。
