## UIKitConfig 配置

```csharp
public class GameUIKitConfig : UIKitConfig
{
    private const string PanelPathPrefix = "UI/";

    public override IPanel LoadPanel(PanelSearchKeys panelSearchKeys)
    {
        FillPrefabPath(panelSearchKeys);
        return base.LoadPanel(panelSearchKeys);
    }

    public override void LoadPanelAsync(PanelSearchKeys panelSearchKeys, System.Action<IPanel> onPanelLoad)
    {
        FillPrefabPath(panelSearchKeys);
        base.LoadPanelAsync(panelSearchKeys, onPanelLoad);
    }

    private static void FillPrefabPath(PanelSearchKeys panelSearchKeys)
    {
        if (panelSearchKeys == null || panelSearchKeys.PanelType == null) return;
        if (!string.IsNullOrEmpty(panelSearchKeys.GameObjName)) return;

        panelSearchKeys.GameObjName = PanelPathPrefix + panelSearchKeys.PanelType.Name;
    }
}
```

我的 UI 预制体 `UITest` 路径为 `Asset/Resources/UI/UITest.prefab`，所有 UI 预制体都放在 `UI` 文件夹下面。

因此需要将 `PanelSearchKeys` 的 `GameObjName` 设置为资源路径名：

```text
UI/UITest
```

## UI 预制体的创建流程

### 1. 搭建 UI 预制体

搭建好 UI 预制体后，右键选择 `@UIKit`，会自动生成一个与预制体名字相同的 C# 文件。

![搭建 UI 预制体](/assets/img/posts/2026-08-26-qframework/ui-prefab.png)

### 2. 添加 Bind 脚本

对于需要作为参数使用的内容，例如图片、按钮，需要挂上 `Bind` 脚本。

![添加 Bind 脚本](/assets/img/posts/2026-08-26-qframework/bind-script.png)

### 3. 生成代码

把生成的 C# 文件挂载到预制体上，然后点击“生成代码”。

![生成代码](/assets/img/posts/2026-08-26-qframework/generate-code.png)

## UIPanel 的通用方法

```csharp
protected override void OnInit(IUIData uiData = null)
protected override void OnOpen(IUIData uiData = null)
protected override void OnShow()
protected override void OnHide()
protected override void OnClose()
```

## UIPanel 生命周期

首次创建时，会依次调用：

```text
OnInit -> OnOpen -> OnShow
```

每次打开时，会调用：

```text
OnOpen -> OnShow
```

每次关闭时，会调用：

```text
OnHide -> OnClose
```

`OnClose` 会销毁预制体，并将其从 UIKit 注册表中移出。
