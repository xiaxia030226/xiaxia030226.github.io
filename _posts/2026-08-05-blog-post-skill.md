本文介绍一个 CodeBuddy skill，用于自动创建博客文章——自动编号、读取 Unity 项目代码并生成 Markdown 格式的开发日记。

## 下载 SKILL.md

将 `SKILL.md` 放入 `~/.codebuddy/skills/blog-post/` 目录下即可使用：

[下载 blog-post SKILL.md](/assets/downloads/blog-post-skill.txt)

---

也可以直接复制以下链接：

```
https://xiaxia030226.github.io/assets/downloads/blog-post-skill.txt
```

## 使用方式

安装后在 CodeBuddy 中直接说：

```
在个人项目开发日记下新增文章，标题叫 EventCenter，
分析 xx/Assets/Scripts/GameFrameWork/Event 文件夹
```

Skill 会自动加载，按 SKILL.md 中定义的流程完成编号、代码分析和文章生成。
